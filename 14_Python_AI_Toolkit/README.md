# Python AI 工具线

本阶段目标：在 Java 主线之外，补一条轻量 Python 工具线，用来学习 AI 生态、快速验证 RAG、MCP 和 Agent 思路。

你的主线仍然是：

```text
Java / Spring Boot / SQL / Redis / Docker
```

Python 在这里的定位是：

```text
AI 实验工具、文档处理工具、RAG 原型、Agent 原型、MCP 工具服务
```

## 为什么要学

公司项目主要用 Java，所以后端主线应该继续放在 Java 和 Spring Boot 上。

但 AI 生态里很多工具、示例和开源项目都优先支持 Python。学一条轻量 Python 工具线，可以让你更快理解 AI 应用的核心流程，再把成熟方案迁回 Java 项目里。

## 学习重点

- Python 基础语法；
- 虚拟环境和依赖管理；
- 调用大模型 API；
- 读取 PDF、Markdown、Word 等文档；
- 文档切分；
- 向量化和相似度检索；
- RAG 基础流程；
- MCP 工具服务；
- Agent 工具调用；
- 将 Python 原型能力迁移到 Java 项目；

## 建议学习顺序

### 01 Python 基础

- 变量、条件、循环；
- 函数；
- 列表、字典；
- 文件读写；
- JSON 处理；

完成标准：能写一个脚本读取文件、整理内容并输出 JSON。

### 02 AI API 调用

- 调用大模型接口；
- 编写 Prompt；
- 处理返回结果；
- 处理超时和错误；

完成标准：能写一个命令行脚本，让 AI 总结一段文本。

### 03 文档处理

- 读取 Markdown；
- 读取 PDF；
- 文本清洗；
- 内容切分；

完成标准：能把一个文档拆成多个适合检索的片段。

### 04 RAG 原型

- 文本向量化；
- 相似内容检索；
- 把检索结果交给 AI 回答；
- 展示引用来源；

完成标准：能做一个最小版“上传资料后问答”的原型。

### 05 MCP

- 理解 MCP 是让 AI 调用外部工具的一种协议；
- 编写简单工具；
- 暴露工具给 AI 使用；

完成标准：能做一个简单 MCP 工具，例如查询本地文件、读取任务列表或调用内部接口。

### 06 Agent

- 理解 Agent 的任务拆解和工具调用；
- 让 Agent 根据目标选择工具；
- 控制执行边界，避免不可控操作；

完成标准：能做一个小型办公助手，例如根据输入生成待办、查询资料、整理摘要。

## 和 Java 主线怎么配合

推荐方式：

1. 先用 Python 快速验证 AI 思路；
2. 确认方案可行后，再用 Java/Spring Boot 接入公司项目；
3. Python 保留为工具服务或离线处理脚本；
4. Java 负责正式业务接口、权限、数据和部署；

## 阶段成果

完成一个“AI 工具实验箱”，包含：

- 文档读取脚本；
- 文档切分脚本；
- AI 总结脚本；
- RAG 问答原型；
- 简单 MCP 工具；
- 简单 Agent 原型；
