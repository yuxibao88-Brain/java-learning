# 知识库问答 RAG

本阶段目标：让 AI 基于你上传的资料回答问题，而不是只依赖模型自己的通用知识。

## 学习重点

- 文档上传；
- 文档内容读取；
- 文档切分；
- 文本向量化；
- 向量数据库；
- 相似内容检索；
- 检索结果拼接进 Prompt；
- 回答时展示引用来源；

## 推荐练习

- 上传 Markdown 或 PDF 文档；
- 将文档拆成多个片段；
- 根据用户问题找出最相关片段；
- 让 AI 基于片段回答；
- 在回答下面展示参考来源；

## 阶段成果

完成一个“个人知识库问答系统”，至少支持：

- 新建知识库；
- 上传资料；
- 针对资料提问；
- AI 回答时给出来源；
- 支持多个知识库切换；
