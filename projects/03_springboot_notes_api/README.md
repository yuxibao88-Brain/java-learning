# 03 Spring Boot 笔记接口

## 项目目标

用 Spring Boot 做一个笔记管理后端，完成从接口到数据库的完整链路。

## 建议功能

- 用户注册；
- 用户登录；
- 新增笔记；
- 编辑笔记；
- 删除笔记；
- 查询笔记列表；
- 按标题或内容搜索；
- 标签分类；
- 文件上传；

## 学习重点

- Spring Boot 项目结构；
- 接口设计；
- 参数校验；
- 统一返回格式；
- 统一错误提示；
- MyBatis-Plus；
- 登录状态处理；

## 完成标准

- 接口可以正常访问；
- 数据能保存到数据库；
- 前端或接口工具可以完成完整增删改查；
- 登录后才能操作自己的笔记；
