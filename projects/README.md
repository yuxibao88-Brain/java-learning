# 小项目目录

这里放每个阶段真正能运行的小项目。

学习资料和笔记放在上层课程目录里，小项目统一放在这里，方便后续持续迭代、展示和复盘。

## 项目顺序

1. `01_console_task_manager`：Java 基础阶段项目，练习语法、集合、方法和面向对象；
2. `02_sql_article_system`：数据库阶段项目，练习表设计和 SQL 操作；
3. `03_springboot_notes_api`：后端接口阶段项目，练习 Spring Boot 和数据库接口；
4. `04_ai_notes_app`：AI 接入阶段项目，把 AI 能力接入笔记系统；
5. `05_knowledge_base_qa`：知识库问答阶段项目，练习资料上传和基于资料问答；
6. `06_ai_workspace_deploy`：最终部署项目，整理成可展示、可上线的 AI 全栈作品；

## 使用建议

- 每个项目都先做最小可运行版本；
- 不要一次追求功能完整，先跑通主流程；
- 每完成一个阶段，在对应项目的 README 里记录成果、问题和下一步；
- 能运行、能演示、能解释，比单纯看完资料更重要；
