# AI 应用部署

本阶段目标：把完整 AI 全栈项目部署到服务器，让别人可以通过网址访问。

## 学习重点

- Linux 基础命令；
- Docker 打包；
- MySQL 部署；
- 后端服务部署；
- 前端静态资源部署；
- Nginx 反向代理；
- 环境变量管理；
- 日志查看；
- 域名和 HTTPS；

## 推荐练习

- 本地打包前端项目；
- 本地打包 Spring Boot 项目；
- 用 Docker 启动数据库和后端；
- 用 Nginx 访问前端页面；
- 把模型 Key 放到环境变量中；

## 阶段成果

将 AI 全栈项目部署上线，至少做到：

- 有一个可访问网址；
- 前端页面正常打开；
- 后端接口正常访问；
- 数据库数据能持久保存；
- AI 功能能正常调用；
- 能查看运行日志并定位问题；
