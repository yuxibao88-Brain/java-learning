# AI 接入

本阶段目标：把大模型能力接入 Spring Boot 项目，让普通业务系统具备 AI 功能。

## 学习重点

- 大模型 API 调用；
- Prompt 编写；
- 流式输出；
- 对话历史保存；
- AI 结果保存；
- 超时、失败重试和错误提示；
- 前端打字机效果；
- Token 成本意识；

## 推荐练习

- AI 总结笔记；
- 自动生成标题；
- 从文本中提取待办；
- 根据输入内容生成周报；
- 保存每次 AI 生成记录；

## 阶段成果

把已有的笔记或内容管理项目升级成 AI 版本，至少支持：

- 输入一段内容，AI 自动总结；
- 输入工作记录，AI 生成周报；
- 前端可以看到流式输出效果；
- 后端保存 AI 生成结果；
